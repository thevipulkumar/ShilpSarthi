# Drop photographs here

Put photos in this folder, put a keyword in each filename, then run:

    npm run photos

The script resizes each one, files it in the right place, and switches the
placeholder off. You do not need to touch any code.

| Keyword in the filename | Where it lands |
| --- | --- |
| `bariatu` | Bariatu project card |
| `harmu` | Harmu project card |
| `villa` | Kanke Road villa card |
| `doranda` | Doranda project card |
| `lalpur` | Lalpur project card |
| `gym` or `fitness` | Anytime Fitness card |
| `kitchen` | Modular kitchen service page |
| `wardrobe` or `bedroom` | Bedroom and wardrobe service page |
| `living` | Living room service page |
| `commercial` or `office` | Commercial service page |
| `full-home` | Full home service page |
| `studio` or `showroom` | The Singh More studio |
| `team` | The team photograph |
| `pm`, `manager` or `portrait` | Project manager portrait |

So `harmu-kitchen-finished.jpg` and `studio-front-desk.jpeg` both just work.

Photos straight off a phone or WhatsApp are fine. Anything under about 900px
wide is skipped with a warning rather than shipped blurry.

Delete the files from this folder once they have imported.
